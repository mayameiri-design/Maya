# ספריית המוסיקה של מאיה

- `library/` - קבצי האודיו (רק עם רישיון מסחרי).
- `index.json` - מטא-דאטה: מקור, רישיון, מצב רוח, אורך.
- `scripts/music.py` - הוספה, חיפוש, מיקס עם הנמכה אוטומטית.

מצב נוכחי: **ריקה**. מקורות חיצוניים (Pixabay, FMA, Openverse, Archive.org, incompetech) חסומים בסביבת הענן.
להוספה: מניחים קובץ בתיקייה זמנית ומריצים `music.py add ...` (ראה `references/music-and-sound.md`).
