# מערכת הכותרות המונפשות (`/home/user/Maya/titles`)

Remotion, 1080×1920, 30fps. קריאה מלאה: `titles/README.md`.

## חמישה סגנונות (כל אחד בעברית RTL ובאנגלית)
| סגנון | מתי | הערה |
|---|---|---|
| MaskRise | הוק אלגנטי, מותג, יוקרה | סריף, מילים עולות ממסכה |
| Tracking | פתיחה קולנועית, משפט רגשי | אות דקה, ריווח מצטמצם |
| Extrude3D | מילה אחת-שתיים חזקות (חדש/מבצע) | **כבד לרנדור, רק אם מאיה ביקשה** |
| ColorWipe | מבצע, הצעה, כותרת מידע | בלוק צבע + שורה מודגשת |
| KineticStack | הוק אנרגטי של 3-4 מילים | מילים ענקיות על הביט |

ערכות צבע: `noir`, `ember`, `ice`, `paper`. מעברים: `inkWipe`, `blurPush`, `slats`.

## עבודה נכונה
1. בחר סגנון לפי הצורך בסרטון, לא "את כולם".
2. הצג **תמונות סטילס** (`npm run stills -- <dir> <comp> <frames>`) ורק אחרי בחירה רנדר.
3. ערוך טקסט/צבע דרך props (`lines`, `sub`, `theme`) - לא קוד אנימציה.
4. אנימציה ממוקמת מאחורי מאיה או מעליה, לא על הפנים; אזור בטוח לאינסטגרם מובנה (`guides:true` להצגה).
5. לשכבה נפרדת: רנדר עם שקיפות (`--codec=prores --prores-profile=4444 --pixel-format=yuva444p10le` או `--codec=vp9`) כדי להעביר לקאפקאט.
6. בענן: `--concurrency=1` (3D נתקע במקביל), ו-`NODE_USE_ENV_PROXY=1` אם צריך רשת.
7. אל תרנדר ריל מלא/כל הסגנונות/תלת-ממד בלי בקשה.
